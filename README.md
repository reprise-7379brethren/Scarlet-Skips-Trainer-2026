## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Scarlet Skips**. This trainer enhances Scarlet Skips by giving players control over jump timing, run survival, upgrade selection, score progression, and rope-skipping performance. It is designed around the game's single-button input system and roguelike upgrade structure.

**Target Audience:** Players who want to practice timing, experiment with different upgrade combinations, survive longer runs, or pursue exceptionally high scores without changing the game's core one-button skipping concept.

## 📖 Detailed Feature Guide

### Movement & Exploration

Scarlet Skips is built around press, hold, and release inputs from a single control. Use the jump assistance and height controls to practice the timing required to keep the rope moving and maintain a stable rhythm. Disable assistance when you want to return to the standard challenge.

### Tools & Inventory

The game does not use a conventional inventory system. Progression is handled through run-based power-up selections. Use the upgrade features when the selection screen appears, then combine and stack upgrades to test different jump-rope builds.

### World & Environment

Scarlet Skips focuses on continuous rope skipping rather than traditional exploration. Runs become more demanding as the player attempts to survive longer and build a higher score. Run protection can be useful when testing how long a build can perform under increasing pressure.

### Combat & Weapons

Scarlet Skips does not center on traditional combat. Its main challenge is maintaining jump timing, surviving missed-input risks, and using power-ups effectively. Combat-related trainer functions are therefore not included.
